# Notification Router

A centralized notification management system built as a multi-module Kotlin Spring Boot application. Users self-subscribe to notifications from GitHub/Buildkite via a Slack bot, with delivery routed through Novu.

## Commands

```bash
# Build
./gradlew :api:bootJar
./gradlew :bot:bootJar

# Run
./gradlew :api:bootRun
./gradlew :bot:bootRun

# Test (always use --no-daemon on Windows)
./gradlew test --no-daemon

# Lint
./gradlew ktlintCheck
./gradlew ktlintFormat    # run after every Kotlin file change

# Stop stuck Gradle daemon
./gradlew --stop
```

**Windows note:** Use `.\gradlew.bat` instead of `./gradlew` in PowerShell.

## Architecture

```
GitHub Webhook / GitHub Actions / Buildkite
           ↓
    api/ (Kotlin Spring Boot)
      Webhook Adapters → EventService → FilterEvaluator
                                 ↓
                           PostgreSQL
                                 ↓
                        NovuService (trigger)
                                 ↓
                    Novu → Slack DM / Web Inbox
           ↓
    bot/ (Kotlin Slack Bolt)
      /notifyme slash commands + modals → Router API
```

- `api/src/main/kotlin/.../service/EventService.kt` — orchestrates event routing

## Local Development

```bash
# 1. Start infrastructure
docker compose up -d

# 2. Seed Novu (Windows)
.\scripts\setup-novu.ps1

# 3. Seed PostgreSQL (Windows)
cmd.exe /c "docker exec -i router_postgres psql -U postgres -d notification_router < seed.sql"

# 4. Run API
./gradlew :api:bootRun --no-daemon

# 5. Run Bot (requires .env with Slack tokens)
./gradlew :bot:bootRun --no-daemon
```

## Kotlin Style

- **Expression-body** for single-expression functions: `fun foo() = service.bar()`
- **Extension functions** for mapping: `.toDto()`, `.toDomain()` — not standalone `mapToDto()`
- **Safe-call chains**: `?.let {}`, `?: return`, `?: throw` — not `if (x == null)`
- **`.also {}`** for side effects in chains (logging, triggering)
- **`filterNot`/`forEach`** chains instead of imperative for-loops with if-checks
- **No unnecessary local variables** — return directly from expressions
- **No `@field:JsonProperty`** — Jackson infers names from Kotlin data class properties
- **No wildcard imports** — always explicit (linting enforces this)
- **`Filter` domain class directly in DTOs** — no separate DTO wrappers for simple value objects

## Testing Gotchas

- **Always use `org.mockito.kotlin.*`** — never `any(Class::class.java)` or `ArgumentCaptor.capture()` (they return `null` and crash Kotlin non-nullable params)
- **Use `org.mockito.kotlin.check {}`** for argument verification
- **WireMock:** Use `WireMockServer` instance for `stubFor()`/`resetAll()`, create `WireMock(port)` client for `verifyThat()`. Never use static `WireMock.verify()` — it defaults to port 8080
- **Shared test config** is in `api/src/test/resources/application-test.yml` — tests just need `@ActiveProfiles("test")`. Do NOT duplicate properties in `@SpringBootTest(properties = [...])` unless test-specific

## Windows Gotchas

- **Git commit hangs** due to GPG signing — always use:
  ```
  cmd /c "git add . && git -c commit.gpgSign=false commit -m \"message\""
  ```
- **Gradle daemon can get stuck** between test runs — use `--no-daemon`, or `.\gradlew.bat --stop` before retrying
- **Spanish batch prompt** (`¿Desea terminar el trabajo por lotes?`) — answer `S` to terminate

## Code Patterns

### Controllers
```kotlin
// Expression-body wrapping service call
@GetMapping("/{id}")
fun getUser(@PathVariable id: UUID) = ResponseEntity.ok(service.getUser(id))

// DELETE returns 204
@DeleteMapping("/{id}")
fun deleteUser(@PathVariable id: UUID) = ResponseEntity.noContent().build<Unit>()
```

### Services
```kotlin
@Transactional(readOnly = true)
fun getUser(id: UUID) = userRepository.findById(id).orElseThrow { NotFoundException(id) }.toDto()

// Extension function mapping (private, in same file)
private fun User.toDto() = UserDto(id = id, email = email)
```

### Webhook Adapters
- `object` singletons with a shared `webhookMapper` in `WebhookPayloads.kt` (configured with `SNAKE_CASE`, no `@JsonProperty` needed)
- Type-safe deserialization: `webhookMapper.readValue<PayloadType>(payload)`
- `when` dispatch on action/event type
- Return subtypes of `NotificationEvent` sealed interface

### Event Model
- `NotificationEvent` sealed interface — each subtype implements `metadata` and `payload` as computed `Map<String, Any>` properties
- `FilterEvaluator` evaluates `List<Filter>` against `event.metadata[filter.field]` — operator matching is case-insensitive
